# ToDo 桌面插件（Electron 版）

你说得对：你要的是**桌面插件**，不是只在浏览器里打开的页面。现在这个项目已经改成 Electron 桌面版，功能保持不变。

## 功能

- 日历视图（可切换月份，标记有待办的日期）
- 待办事项（添加、删除、搜索、完成）
- 已完成列表（可恢复/清空）
- 可切换风格（浅色、深色、森林）
- 任务统计（总数、完成数、逾期数）
- 本地存储（刷新窗口不丢数据）

## 运行方式（桌面应用）

1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动桌面插件：
   ```bash
   npm run start
   ```

启动后会打开独立桌面窗口，不需要浏览器标签页。

## 文件说明

- `main.js`：Electron 主进程，负责创建桌面窗口
- `index.html` + `script.js` + `styles.css`：插件界面与交互逻辑
